# Шпаргалка по Markdown

Слева — что писать, справа в блоках кода — синтаксис. Скопируйте нужное и подставьте свой текст.

---

## Заголовки

```markdown
# Заголовок 1 уровня
## Заголовок 2 уровня
### Заголовок 3 уровня
#### Заголовок 4 уровня
##### Заголовок 5 уровня
###### Заголовок 6 уровня
```

Решётка `#` отделяется от текста пробелом. Уровней всего шесть.

---

## Выделение текста

```markdown
*курсив* или _курсив_
**жирный** или __жирный__
***жирный курсив***
~~зачёркнутый~~
`код в строке`
```

Результат: *курсив*, **жирный**, ***жирный курсив***, ~~зачёркнутый~~, `код`.

---

## Списки

Маркированный (можно `-`, `*` или `+`):

```markdown
- Первый пункт
- Второй пункт
  - Вложенный пункт (отступ в 2 пробела)
  - Ещё один вложенный
- Третий пункт
```

Нумерованный (числа могут быть любыми — Markdown пересчитает сам):

```markdown
1. Первый
2. Второй
3. Третий
```

Список задач (чекбоксы):

```markdown
- [x] Выполнено
- [ ] Не выполнено
```

## Ссылки и изображения

```markdown
[текст ссылки](https://example.com)
[ссылка с подсказкой](https://example.com "появится при наведении")

![альтернативный текст](path/to/image.png)
![картинка с подсказкой](image.png "подпись")
```

Изображение отличается от ссылки только восклицательным знаком `!` в начале.

Ссылки-сноски (удобно, если URL длинный или повторяется):

```markdown
Смотри [документацию][docs] для деталей.

[docs]: https://example.com/docs
```

## Код

Внутри строки — одинарные обратные кавычки:

```markdown
Команда `git status` показывает статус.
```

Блок кода — тройные кавычки, после них можно указать язык для подсветки:

````markdown
```python
def hello():
    print("Привет")
```
````


## Таблицы

```markdown
| Колонка 1 | Колонка 2 | Колонка 3 |
|-----------|:---------:|----------:|
| слева     | по центру | справа    |
| текст     | текст     | текст     |
```

Двоеточия в строке-разделителе задают выравнивание:
`:---` слева, `:---:` по центру, `---:` справа.

## Горизонтальная линия

```markdown
---
```

Три и более дефиса, звёздочки или подчёркивания на отдельной строке.

## Переносы и абзацы

```markdown
Пустая строка между блоками создаёт новый абзац.

Два пробела в конце строки  
дают перенос внутри абзаца.
```

## Экранирование символов

Чтобы показать служебный символ как текст, поставьте перед ним `\`:

```markdown
\*это не курсив\*
\# это не заголовок
```

Экранировать можно: `\` `` ` `` `*` `_` `{}` `[]` `()` `#` `+` `-` `.` `!` `|`

---

## Частые ошибки

- После `#`, `-`, `>` нужен **пробел** перед текстом, иначе разметка не сработает.
- Между блоком текста и списком/таблицей/цитатой оставляйте **пустую строку**.
- Для вложенных списков используйте одинаковый отступ (обычно 2 пробела).
- Внутри таблиц переносы строк не работают — используйте `<br>` при необходимости.

## HTML внутри Markdown

Большинство движков допускают вставку HTML, когда возможностей Markdown не хватает:

```markdown
<details>
<summary>Нажми, чтобы раскрыть</summary>

Скрытый текст здесь.

</details>

Текст с <br> переносом и <sub>нижним</sub> / <sup>верхним</sup> индексом.
```
