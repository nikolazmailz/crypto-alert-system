# Engineering Guidelines

Документ описывает базовые инженерные договорённости команды.
Цель — сделать разработку предсказуемой, код поддерживаемым, а процессы понятными для всех участников.

---

## Общие принципы

- Пишем код так, чтобы его мог поддерживать другой разработчик.
- Предпочитаем простые и понятные решения сложным абстракциям.
- Любое нетривиальное техническое решение должно быть объяснимо.
- Если договорённость устарела — обновляем этот документ.

## Definition of Done

Задача считается завершённой, если:
- код написан;
- тесты добавлены или обновлены;
- все тесты проходят;
- PR прошёл ревью;
- документация обновлена, если это необходимо;
- изменения задеплоены или готовы к деплою;
- нет известных блокирующих проблем.
