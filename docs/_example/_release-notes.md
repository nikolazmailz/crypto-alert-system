## Release Notes

Фактическое описание того, что вышло в релизе.

### Added

- Добавлен аудит получения списка заявок.
- Добавлен аудит получения информации о пользователе.

### Fixed

- Исправлена ошибка при получении оргструктуры.
- Исправлена обработка пустого ответа от внешнего сервиса.

### Changed

- Обновлена конфигурация audit events.
- Изменён формат логирования интеграционных запросов.

### Migration / Configuration

- Добавлены новые параметры в `application-audit-events.yml`.
- Требуется обновить переменные окружения для Kafka.

### Risks

- Изменения затрагивают аудит и интеграцию с внешними сервисами.
- Нужно проверить happy path по заявкам и оргструктуре.
